# Nothing Landing Page

A modern, responsive landing page for Nothing brand products. Built with semantic HTML and SCSS following BEM methodology.

## 🎨 Design:
- [Nothing](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6802-139&t=L7eKz5YKLN0m5WxR-0)

## 🚀 Preview
- [DEMO LINK](https://Yevhen-Srdk.github.io/Nothing-Landing-Page/)

## 🛠 Technologies Used

- HTML5
- SCSS (Sass)
- BEM Methodology
- CSS Grid & Flexbox
- GitHub Pages

## ✨ Features

- Fully responsive design (Mobile, Tablet, Desktop)
- Modern UI/UX following Nothing brand aesthetics
- Semantic HTML markup
- Modular SCSS architecture
- Smooth animations and transitions
- Contact form
- Product categories showcase

## 🎯 Learning Outcomes

This project helped me learn:
- Building responsive layouts with CSS Grid
- SCSS preprocessing and variables
- BEM naming convention
- Mobile-first approach
- Cross-browser compatibility
- Git workflow and GitHub Pages deployment
